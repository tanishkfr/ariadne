# Ariadne 1.5.3

Ariadne carries a creative project from an ordinary-language brief through
research, design direction, implementation and independent review while keeping
creative and release authority with the human owner.

## Install

```bash
python -m pip install --user "https://github.com/tanishkfr/ariadne/releases/download/v1.5.3/ariadne-1.5.3-py3-none-any.whl"
python -m ariadne install
python -m ariadne doctor
```

## Requirements

- Python 3.8 or newer.
- Codex for the managed `$ariadne` entry skill.
- No project backend, database, CMS, authentication system or paid service is
  installed unless the project itself requires it and the human approves it.

# MODE: Content system

Writing for X and LinkedIn, with analytics and a learning loop. **The only ongoing mode** — it does not ship and finish, it runs weekly.

Full method: [CONTENT-SYSTEM.md](../CONTENT-SYSTEM.md). This file is the routing.

---

## Detection

**Signals:** "post", "tweet", "LinkedIn", "content", "audience", "engagement", "voice", "personal brand".

**Not this mode if:** it is copy for a website (that is part of the site's mode), or a blog as a built artifact (personal portfolio).

---

## Questions

1. **Which platforms?** — default: X and LinkedIn
2. **What are you actually known for, or want to be?** — no default
3. **What do you refuse to post?** — default: none, but push for at least three. This list is more useful than the topics list.
4. **Do you have access to past post analytics?** — default: assume no history
5. **What cadence is realistic?** — default: 2-3 posts a week. Be honest; an unrealistic cadence produces filler, and filler is worse than silence.

---

## Setup, once

Three artifacts, built at S1-S2, living **in the content project, never in the Builder OS** ([PRIVACY-POLICY.md](../PRIVACY-POLICY.md)):

**1. `voice-profile.md`** — from 10-20 things you have actually written. Includes the **anti-voice list**: constructions you find embarrassing. Minimum ten entries. Easier to enforce than a voice list and does more work.

**2. Content pillars** — 3-5 subjects you can post on for a year. Each needs a specific personal instance you can point to. A pillar without one is a topic; drop it.

**3. [`CONTENT-LEARNINGS.md`](../templates/CONTENT-LEARNINGS.md)** — starts empty. This is where the loop closes.

## Gates

**G5 only, and it fires on every single post.** No standing approval exists or can be granted.

G2 applies if a scheduling or analytics tool is proposed. The default answer is no — this system has no account access by design.

## The weekly rhythm

| When | What | Time |
|---|---|---|
| While building | Capture instances in `RETROSPECTIVE.md` files | 0 — it is a side effect |
| Drafting day | Idea → hook (score 4+) → draft → originality checks → G5 | 30 min per post |
| Posting | **You** copy and post it | 5 min |
| Weekly | Review, update `CONTENT-LEARNINGS.md` | 20 min |
| Quarterly | Re-read all learnings, prune rules, check voice drift | 45 min |

**Retrospectives are the best idea source you have.** Real instances with specifics, already written down. Ideation that starts from a topic instead of an instance produces the statistical centre of the discourse.

---

## Quality bar

Per post, all of these:

- **The only-you element** — one thing nobody else could have written. **Without it, do not post.**
- **Hook scores 4+** — below 4 does not get drafted
- All five originality checks pass ([CONTENT-SYSTEM.md](../CONTENT-SYSTEM.md) section 8)
- Passes the read-aloud test
- Zero fabricated metrics, clients, results, or experiences

## Hard limits

- **Nothing publishes automatically.** Ever.
- No account connections, no scheduling, no bulk posting.
- Analytics come from you, pasted in. The system has no account access and must not imply otherwise.
- Never invent a number, a client, or an experience. [WORKFLOW.md](../WORKFLOW.md) Red tier.

---

## Failure modes

| Failure | Countermeasure |
|---|---|
| Topic-first ideation producing generic takes | Start from an instance in a retrospective |
| Posting to hit a cadence | Realistic cadence at question 5; silence beats filler |
| Building a rule from one good post | Three occurrences before promotion |
| Chasing impressions | Qualitative column in `CONTENT-LEARNINGS.md` |
| Cross-posting identical text | Write each version from the idea, not from each other |
| The loop never closing | A weekly review that changes nothing is not a review |
| Drifting into LinkedIn slop | The anti-voice list, swept every draft |

# SKILL: content-strategy

**Trigger** — content mode, or a post is needed.
**Owner** — Content strategist · **Class** — `R1`
**Inputs** — voice profile, pillars, [`CONTENT-LEARNINGS.md`](../templates/CONTENT-LEARNINGS.md), analytics you paste in
**Output** — drafts, platform adaptations, weekly reviews

Full system: [CONTENT-SYSTEM.md](../CONTENT-SYSTEM.md). This file is the drafting procedure.

**Nothing publishes automatically. G5 is per-post, every post.**

---

## Method

**1. Start from a real instance, not a topic.** Something that happened while building: a bug, a decision, a thing you were wrong about. `RETROSPECTIVE.md` files are the best idea source you have.

Never ask a model "what should I post about". That returns the statistical centre of the discourse, which is where every generic post already lives.

**2. Find the only-you element.** A specific number, a real conversation, a dated mistake, a thing you changed your mind about. **A post without one is a generic take** — and generic takes read as AI whether or not they are.

If there is no only-you element, the post is not ready. Do not draft it.

**3. Write the hook and score it 1-5** ([CONTENT-SYSTEM.md](../CONTENT-SYSTEM.md) section 6). **Below 4 does not get drafted.** The most common failure is a 5-quality idea with a 2-quality hook.

**4. Draft the idea platform-neutral first.** The claim, the specific instance, the tension. Then write each platform version *from the idea*, never from the other version. Adaptations of adaptations lose the point.

**5. Apply the voice rules** ([CONTENT-SYSTEM.md](../CONTENT-SYSTEM.md) section 5). The ones that do most of the work:

- Vary paragraph length dramatically. One sentence. Then five.
- Do not resolve everything. An open question you actually have is fine.
- Never open with a rhetorical question.
- Never close with a tidy lesson.
- Avoid three parallel examples — use one in detail, or two of unequal weight.
- Cut every intensifier that is not load-bearing.

**6. Run the originality checks** ([CONTENT-SYSTEM.md](../CONTENT-SYSTEM.md) section 8): only-you, anti-voice sweep, structure check, prior-art check, read-aloud.

**7. Flag your own AI tells.** If a draft has the LLM shape — the three-part structure, the em-dash reversal tic, the neat closing lesson — **say so and offer an alternative.** A draft that arrives with "the close reads AI-generated, here's another version" is doing the job properly.

**8. Present for G5** in the format in [CONTENT-SYSTEM.md](../CONTENT-SYSTEM.md) section 9. You copy the text and post it yourself.

## Weekly review

Twenty minutes, appended to `CONTENT-LEARNINGS.md`:

1. What went out, how did each do?
2. Best and worst — is the difference explainable, or noise?
3. Any hypothesis supported or contradicted?
4. What did people respond to in *replies*, not counts?
5. One change for next week. One.

**Promote a pattern to a rule only after it holds three times.** Two data points is a coincidence. This is what separates a learning system from a superstition generator.

**Qualitative beats quantitative.** One reply from someone whose work you respect outweighs 5,000 impressions. Record it, because impression counts will not.

---

## Hard rules

- Never invent a metric, a client, a result, or an experience. [AUTONOMY-POLICY.md](../AUTONOMY-POLICY.md) Red tier.
- Never claim expertise you do not have.
- Never connect to an account, schedule, or bulk-post.
- Never cross-post identical text.
- Analytics come from you. The system has no account access and must not imply otherwise.

---

## Done when

The only-you element is present · hook scores 4+ · all five originality checks pass · platform versions written from the idea · G5 presented with the exact text.

---

## Failure modes

| Failure | Countermeasure |
|---|---|
| Topic-first ideation | Step 1: start from a real instance |
| Generic take with no anchor | Step 2 is a hard gate |
| Good idea, weak hook | Score before drafting |
| LinkedIn one-line-per-sentence slop | Real paragraphs, occasional breaks |
| Threads that should be one post | Thread only for genuinely sequential ideas |
| Building a rule from one good post | Three occurrences minimum |
| Fabricated specifics to strengthen a post | Red tier. Never. |

# AR-224 Trust Model

Claim is not evidence.

Evidence is not acceptance.

Missing evidence is not failure.

Worker is not independent reviewer.

Confidence is not permission.

Evidence belongs to a particular revision.

Changed work can invalidate proof.

Human authority remains human authority.

## Consequences

- A worker completion claim never satisfies its own requirement.
- UNPROVEN means no evidence either way; FAILED means evidence of violation.
- CONTRADICTED means a worker statement is disproved by evidence.
- NEEDS_HUMAN is a first-class outcome, not a failure to decide.
- Promotion grants decision eligibility, never action authority.
  `authorization_effect: none` always.
- Proof means evaluated against these requirements using this evidence,
  not bug-free.
- Prompt injection is bounded by authority, not magically eliminated.
- Proof Pass evaluates declared requirements and evidence; it does not
  prove all bugs absent.

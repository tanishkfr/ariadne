# Brand assets

These are the maintainer-supplied Ariadne brand assets, cropped from the single
authorized source image for use in this repository.

| File | Use |
|---|---|
| `ariadne-banner.png` | The README banner and release/social presentation (dark background). |
| `ariadne-logo.png` | Mark and wordmark on a light background. |
| `ariadne-mark.png` | The mark alone on a light background. |
| `ariadne-wordmark.png` | The wordmark alone on a light background. |

They are raster crops of the supplied artwork; final vector versions
(`ariadne-mark.svg`, `ariadne-wordmark.svg`, `ariadne-banner.svg`) belong here
when the maintainer supplies them. Do not generate replacement branding.

The README references `ariadne-banner.png` directly, so swapping in a new file
with the same name updates the published page without further edits.

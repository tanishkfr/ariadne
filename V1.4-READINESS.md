# BUILDER OS V1.4 READINESS

## 1. V1.4 status

**NEAR READY.** `[BUILT][VERIFIED]` The installable product and local release
pipeline are complete. `[BLOCKED]` Public use awaits an owner-approved licence
and explicit publication of the first GitHub release.

## 2. Installation architecture

`[BUILT][VERIFIED]` A dependency-free Python launcher installs an embedded,
hashed runtime into versioned user-local storage and atomically registers its
managed Codex skill.

## 3. Distribution mechanism chosen

`[BUILT]` The release set is a platform-neutral wheel, runtime ZIP, release JSON
and SHA-256 files attached to one matching GitHub tag.

## 4. Why it was chosen

`[VERIFIED]` One Python package works in the Windows test environment without a
shell bootstrap, admin rights, external build dependency or repository clone.
`[REASONABLY ASSUMED]` The same pure-Python wheel is portable to macOS/Linux.

## 5. `$builderos` installation status

`[VERIFIED]` Install, drift detection, repair, update and rollback keep exactly
one managed skill pointed at the active runtime. Unknown files and unmanaged
skills are preserved and block replacement.

## 6. Runtime installation status

`[VERIFIED]` The wheel's embedded runtime installs without network access or a
source checkout. Every runtime file is named and hashed in its release manifest.

## 7. Versioning

`[BUILT][VERIFIED]` [VERSION](VERSION) is authoritative. Package metadata,
runtime names, CLI output and release assets derive from it; mutation tests
reject a second package version.

## 8. Update mechanism

`[BUILT][VERIFIED]` `python -m builderos update` reads one HTTPS release
descriptor, verifies archive and internal hashes, preserves configuration and
projects, and activates only after preparing the matching skill.

## 9. Rollback

`[BUILT][VERIFIED]` `python -m builderos rollback` switches to the prior healthy
version and skill. Interrupted runtime and pointer updates retained the earlier
active installation in deterministic tests.

## 10. Uninstall

`[BUILT][VERIFIED]` `python -m builderos uninstall` removes installed runtime and
managed skill while preserving project source and external run history. Pip
removes the small launcher in a separate explicit command.

## 11. `builderos doctor`

`[BUILT][VERIFIED]` Doctor reports Python, installation, runtime hashes, skill
parity, Codex detection and optional project compatibility in plain language.
Missing Codex is a warning; damaged runtime or incompatible state is blocking.

## 12. Project independence

`[VERIFIED]` Installation and update do not write to a project. The clean-venv
test started an ordinary project from the installed runtime with no checkout
pointer or canonical-source copy.

## 13. Existing-project adoption

`[VERIFIED]` Existing runtime controls still inspect before adoption, preserve
source, and refuse to overwrite `PROJECT.md` or `AGENTS.md`. The skill now
chooses that safe path from ordinary language without exposing the flag.

## 14. First-run UX

`[VERIFIED]` Successful install explains what Builder OS handles, what remains
human-controlled and one next action. Its normal response contains no stage,
packet, manifest or adapter terminology.

## 15. README and quickstart

`[BUILT]` [README.md](README.md) now opens with product purpose, audience,
install, start and human control. [QUICKSTART.md](QUICKSTART.md),
[INSTALL.md](INSTALL.md), [UPDATE.md](UPDATE.md) and
[TROUBLESHOOTING.md](TROUBLESHOOTING.md) separate normal use from maintenance.

## 16. Security considerations

`[VERIFIED]` Updates require HTTPS and SHA-256 parity; archives reject absolute,
parent, backslash and symlink paths. Release contents use an explicit allowlist.
`[EXTERNALLY UNVERIFIED]` Published-release attestation is unavailable until a
real immutable release exists.

## 17. Cross-platform status

`[VERIFIED]` Windows wheel installation and runtime execution passed.
`[REASONABLY ASSUMED]` macOS and Linux user paths and the standard-library logic
passed isolated simulation. `[EXTERNALLY UNVERIFIED]` Native runs on those two
platforms have not occurred.

metadata, launcher command, simple first action, embedded runtime, doctor,

## 19. Failure and recovery results

## 20. Release and distribution process

`[BUILT][VERIFIED]` The deterministic release builder passed 11/11 and refuses a

assets → tag → immutable release → clean-machine verification.

## 21. Remaining friction

`[BLOCKED]` The public install URL is not live. `[REASONABLY ASSUMED]` Some Python

## 22. Still developer-only

## 23. Externally unverified
